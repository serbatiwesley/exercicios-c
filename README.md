# Exercícios de C

Repositório com os exercícios de linguagem C desenvolvidos ao longo do primeiro semestre do curso de Ciências da Computação. O conteúdo está organizado por assunto, do mais básico ao mais avançado, e inclui tanto exercícios pontuais quanto pequenos projetos mais completos.

## Estrutura

```
01_basico/              Fundamentos: entrada/saída, condicionais, laços, operadores
02_funcoes/              Funções, parâmetros e retorno
03_repeticao_fluxo/      Estruturas de repetição aplicadas a problemas mais elaborados
04_structs_ponteiros/    Structs, ponteiros e passagem por referência
05_malloc_realloc/       Alocação dinâmica de memória
06_recursao/             Funções recursivas, incluindo recursão em cauda
07_miniprojetos/         Programas mais completos, combinando vários conceitos acima
```

Cada arquivo `.c` corresponde a um exercício específico. Arquivos de apoio, usados apenas como referência de sintaxe (não exercícios resolvidos), têm o prefixo `demo_` no nome.

## Sobre este repositório

Este material está em constante revisão: arquivos antigos são reescritos conforme novos conceitos são aprendidos, mantendo o histórico de commits como registro da evolução.
